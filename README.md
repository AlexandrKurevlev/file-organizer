# ПОРТ — Программа Организации Разнообразных Типов

Учебный проект по основам Go. Утилита для автоматической сортировки файлов по типам.

## Возможности

- Автоматическая сортировка файлов по расширениям
- Логирование всех операций
- Отчёт со статистикой
- Обработка конфликтов имён

## Установка

git clone https://github.com/AlexandrKurevlev/file-organizer.git
cd file-organizer
go build

## Использование

./file-organizer
